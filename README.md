# Calculadora de Desconto

Projeto da disciplina CMP2304 - Tecnologia de Construção de Software (PUC Goiás)
Aluna:  Ana Clara Nery e Mello Figueiredo

Aplicação web que recebe o preço original de um produto e o percentual de desconto,
calculando o valor final a ser pago e quanto foi economizado.

- Site publicado: https://calculadora-desconto-pi14.vercel.app
- Stack: HTML, CSS e JavaScript (sem dependências)
- Versionamento: Git e GitFlow (main, develop, feature, release e hotfix)
